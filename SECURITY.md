# Security Policy

## Reporting a vulnerability

Report suspected security vulnerabilities privately to security@uldren.ai. Do
not open public issues, pull requests, or discussions for security reports.

Include the affected component, a description of the issue, reproduction steps
or a proof of concept, and any relevant version, commit, or configuration
detail.

## Handling

Reports are acknowledged, investigated, and addressed through coordinated
disclosure where appropriate.

## Scope

This policy covers the Uldren Core repository. Release metadata identifies
supported versions; fixes outside a supported release line are applied to
`main`.
